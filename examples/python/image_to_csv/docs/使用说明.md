# 水表图片转 CSV 客户端使用说明

## 启动

需要 Python 3.9 或更新版本，无额外依赖。在客户端目录执行：

```text
python -B run.py
```

打开终端打印的本机网址即可使用。程序只监听本机回环地址，默认由系统分配空闲端口。按 Ctrl+C 停止。

默认数据保存在用户目录的 `.watermeter-image-to-csv` 中，也可用 `--data-dir` 指定专用目录。`--port` 可指定本机端口。输入图片和 `session.json` 保存在该目录，包含人工核对状态和已提交任务ID；请按自己的图片隐私要求保管。API Key 不写入该文件。

## 离线演示

点击“体验离线演示”，加载三张程序绘制的水表示意图及预设读数。其中一行没有有效读数，供练习人工复核。所有演示行明确标注 DEMO，始终跳过真实API识别。

选择一行，在右侧查看示意图和AI原值，填写人工确认值、勾选“我已核对这个读数”，点击“保存核对”。AI原值保持，人工值单独保存。点击“导出CSV”即可下载表格。

## 识别自己的图片

1. 选择一张或多张 JPEG、PNG、WEBP 图片，每张最多20MB。同一内容重复导入会合并，单次核对会话最多200张；这是客户端会话容量，不是账号免费额度。
2. 在官网创建API Key，填入本工具后点击“连接并查询额度”。程序从账号的公开额度接口读取实际额度，密钥只保存在本机程序内存中，输入框随即清空。
3. 点击“开始／继续识别”后，程序逐张上传非演示图片并查询任务进度。导入本身不提交图片。开始处理后新导入的图片留到下一次手动开始。
4. 对照原图核对结果。没有正式有效读数的项目保留为空，不能将诊断中的部分数字当成正式读数。
5. 人工核对后导出CSV，失败和未确认的行也会保留。

上传的图片交由 WaterMeter AI 在线服务处理，适用账号当前的服务规则和额度。本工具不另外发放或强制承诺月度免费次数。

## 暂停、恢复和异常

“暂停”停止后续提交及本机轮询，不取消已经提交到服务端的任务。再次开始会复用保存的任务ID查询结果。重新启动程序后需要重新提供API Key；不会从浏览器存储或本机会话文件恢复密钥。

若显示“需核查提交”，表示上传响应未能确认，或程序在提交过程中被关闭。该行不会自动重发。请先到官网核对任务历史，再决定后续处理，避免重复消耗额度。

轮询收到429时遵循`Retry-After`等待；明确的提交拒绝会停止本轮处理，等待用户解决额度、权限或配置问题。

## CSV字段

`filename`为原文件名，`ai_reading`为AI正式原值，`confirmed_reading`为填写的人工值，`selected_reading`在勾选核对后采用人工值，否则采用AI原值。`status`、`reviewed`、`result_source`和`note`保留来源及核对情况。

读数按文本写入CSV，原始前导零、小数位保留；Excel自动打开CSV可能重新解释数字，应通过“从文本/CSV”导入，并将读数列设为文本。文件名、备注等以公式符号开头的内容会加文本前缀，防止表格软件执行公式。

## 开发验证

```text
python -B tests/test_client.py
```

测试使用隔离临时目录和本机模拟API，不调用生产识别、不发送邮件。真实水表识别效果须使用有效测试API Key和对应图片单独核验。
