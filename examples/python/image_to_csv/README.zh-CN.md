# WaterMeter Image-to-CSV：水表图片识别与表格导出

[English](README.md) · [API 调用示例](../../../README.md)

这是水表项目下的客户端子项目，目标是把一张或一批水表图片整理为可人工核对、修改并导出的读数表，通过 WaterMeter AI 公开 API 完成识别。

**先访问[水表识别官网 watermeterai.com](https://watermeterai.com/zh-cn)体验识别。在官网[免费注册](https://watermeterai.com/zh-cn/login?flow=register)并登录，即可[免费创建API Key](https://watermeterai.com/zh-cn/api-keys)，接入本工具。普通免费账号每天可识别20次，官网与所有API工具共用同一账号额度，特殊账号按实际额度执行。** 接入步骤见[中文API文档](https://watermeterai.com/zh-cn/api-docs)。

**当前状态：可运行的本机原型。** 已实现图片导入、API提交与轮询、离线演示、人工核对、暂停恢复及CSV导出。自动测试使用本机模拟API；该客户端的生产真实识别尚未核验，尚未提供桌面安装包。

## 启动

需要Python 3.9或更新版本，无需安装额外依赖。在本目录运行：

```text
python -B run.py
```

打开程序打印的本机网址，点击“体验离线演示”即可先试核对和导出；处理自己的图片时，再连接自己的API Key。按Ctrl+C停止。默认数据目录为用户目录下的`.watermeter-image-to-csv`，可通过`--data-dir`指定其它目录。

密钥只保留在本机程序内存中，不写入会话文件或浏览器存储。导入图片不会上传，点击开始识别后才调用在线API。完整操作、恢复及CSV字段说明见[使用说明](docs/使用说明.md)。

## 已实现功能

1. 导入单张或多张指针表、机械数字表图片。
2. 使用用户自己的 API Key 提交识别并查询进度。
3. 并排核对原图、AI 原始读数和识别状态。
4. 单独记录人工确认读数，保留原始 AI 结果。
5. 导出文件名、读数、状态及备注等 CSV 字段；未读出项目保留供核对。

API 调用遵循账号当前的服务端额度和服务规则，实际可用次数以官网及额度接口为准。

普通免费账号**每天免费识别20次**，与官网共用同一账号额度，按服务端自然日（通常为北京时间）重置，未用完不累积。界面显示服务端实际每日上限、今日已用和剩余，处理完成后刷新。查询进度和离线演示不消耗识别次数；付费、自定义及合作账号按各自服务端额度执行。

离线演示使用明确标注的示意图和预设结果，不产生识别调用。未读出及失败行会保留，AI原值与人工确认值分别保存。暂停后继续查询已有任务；提交响应不确定时不自动重发。
