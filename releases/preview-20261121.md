# WaterMeter AI client tools — 0.1.0 testing preview

**Visit [watermeterai.com](https://watermeterai.com/) to try AI water meter reading in your browser. [Register for free](https://watermeterai.com/en/login?flow=register), then [create your API key for free](https://watermeterai.com/en/api-keys).** Ordinary free accounts include **20 recognitions per day**, shared across the website and all API clients. Unused calls do not roll over; paid, custom, and cooperation accounts use their actual quotas. [Read the API documentation](https://watermeterai.com/en/api-docs).

This release contains two source packages and SHA-256 checksums. It is a **testing preview**: Home Assistant host installation, real camera capture, and production recognition end-to-end tests are pending. Local test results use mock APIs and are not recognition accuracy measurements. These are API clients; recognition requires the cloud service and the user's own key. The clients do not include a recognition model.

| Download | Purpose | How to start |
| --- | --- | --- |
| `watermeter-image-to-csv-0.1.0.zip` | Import water meter images, review AI values, keep manual corrections, export CSV | Extract, open `image_to_csv`, run `python -B run.py` with Python 3.9+. Use the offline demo without a key. Source package; no desktop installer. |
| `watermeter-ai-0.1.0.zip` | Manually installed Home Assistant custom integration for an existing camera; cumulative reading, review buttons, and quota sensor | Extract and copy `custom_components/watermeter_ai` to your HA configuration directory; restart HA, add WaterMeter AI. Actual host compatibility remains unverified. |
| `SHA256SUMS.txt` | Integrity checksums for the two ZIPs | Compare SHA-256 values after downloading. |

The Home Assistant integration uploads only when explicitly requested or when you enable your own automation. First readings and large forward changes require review; backwards and rejected readings preserve the previous total. It is a manual custom integration, with no claim of HACS or official Home Assistant inclusion. Do not treat a simulated demo as a verified camera reading.

Client source is provided under the included MIT license. Source packages contain no API key, customer image, model, or private backend code. Protect your own API key; Home Assistant configuration backups can contain it. Submit reproducible problems through [GitHub Issues](https://github.com/tankfly2024/water-meter-ai-api-examples/issues) without keys or private photos.
